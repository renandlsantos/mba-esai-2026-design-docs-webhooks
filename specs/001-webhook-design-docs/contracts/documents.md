# Contrato da entrega documental

PRD deve explicitar problema, público, objetivos/métricas, escopo, não escopo (>=2), requisitos, dependências, riscos, aceite e testes.
RFC deve registrar autor/status/data/revisores, proposta, >=2 alternativas descartadas, >=2 pontos abertos, riscos e links para ADRs.
FDD deve expor integração com >=4 caminhos existentes, modelo proposto, fluxo transacional/worker, HTTP, erros WEBHOOK_*, resiliência, observabilidade e testes.
ADRs: exatamente seis nesta entrega; status/contexto/decisão/alternativas/consequências e código real.
TRACKER: colunas ID, Documento, Tipo, Conteúdo (resumo), Fonte, Localização; >=70% linhas TRANSCRICAO, >=5 referências CODIGO e >=80% do inventário identificável coberto.
README: navegação, ferramentas, processo, >=2 prompts reais e >=2 iterações reais. Não alegar implementação ou validação externa.
